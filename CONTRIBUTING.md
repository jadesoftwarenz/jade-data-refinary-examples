# Contributing

## Purpose

This repository contains tutorial support assets for Jade Data Refinery examples.
Contributions should keep the repository focused on runnable tutorial material.

## Contribution Principles

- Keep changes minimal and explicit.
- Prefer additive updates over broad refactors.
- Preserve compatibility with the published tutorial flow.
- Do not remove source provenance notes from documentation.

## Artifact Policy

- Imported assets in this repository are copies from approved source repositories.
- Do not move or edit source assets in upstream repositories from this repository.
- Keep imported files traceable in docs/artifact-catalog.md.

## Transition Policy

Current bundle and contract artifacts are bootstrap assets.
When EMS authoring workflow becomes available for this example, update the repository to use EMS source plus generated outputs.

## Pull Request Checklist

- Update docs/artifact-catalog.md if files are added or replaced.
- Confirm excluded test-only bundles remain excluded unless explicitly approved.
- Keep file content ASCII where practical.
- Include a clear summary of intent and impact in the pull request description.
