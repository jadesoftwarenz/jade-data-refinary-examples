# Contributing

## Purpose

This repository contains tutorial support assets for Jade Data Refinery examples.
Contributions should keep the repository focused on runnable tutorial material.

## Contribution Principles

- Keep changes minimal and explicit.
- Prefer additive updates over broad refactors.
- Preserve compatibility with the published tutorial flow.

## Example Assets

- Keep example files, the artifact catalog, and tutorial descriptions consistent.
- Include only assets needed to use the documented examples.
- Do not add credentials, customer data, or environment-specific configuration.

## Pull Request Checklist

- Update docs/artifact-catalog.md if files are added or replaced.
- Keep file content ASCII where practical.
- Include a clear summary of intent and impact in the pull request description.
