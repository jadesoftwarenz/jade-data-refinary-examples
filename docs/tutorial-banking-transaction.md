# Banking Transaction Example (V1)

This page describes the local example artefacts provided for the banking transaction tutorial.

## Purpose

This repository provides a stable, copy-only V1 example package that can be used alongside the JDR tutorial without depending on test-only bundles.

## Included Example Assets

- Full main bundle: `f81d4fae-7dec-11d0-a765-00a0c91e6bf6`
- Banking schema artefacts required for the example model
- Banking demo CSV data
- Expected transaction output artefacts

## Exclusions

- Test-only bundles from other secure bundle IDs are intentionally excluded.
- One-off utility scripts are intentionally excluded.

## Transition Note

The included bundle/contracts are temporary bootstrap artefacts for V1.

Once EMS authoring and compile workflow is available for this example, these contracts will be replaced by EMS source and generated outputs.
