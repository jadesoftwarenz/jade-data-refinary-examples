# Jade Data Refinery Example Repository

This repository contains a runnable V1 banking example for Jade Data Refinery (JDR), intended to support the tutorial flow in the main documentation.

## V1 Scope

- Copy-only import of required artefacts from `jade-data-refinery-tools/resources`.
- One included bundle only: `f81d4fae-7dec-11d0-a765-00a0c91e6bf6`.
- No test-only bundle variants included.
- Example output artefacts for transaction verification.

## Important Note

The current bundle and contract artefacts are bootstrap assets for V1.

These artefacts will be replaced by EMS-authored and compiled outputs when the EMS workflow for this example is available.

## Repository Layout

- `docs/` - tutorial-facing notes and manifest.
- `examples/banking-transaction/` - runnable example artefacts.
- `schemas/banking/` - banking schema inputs used by the example.
- `data/banking-demo/` - demo CSV data.
